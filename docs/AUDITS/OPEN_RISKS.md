### R-05 Память и thermal-гейт на границе порога

- **Факт:** `hw.memsize` 18.0 GiB; `vm_stat` на момент аудита: free 12 080 страниц
  (≈189 MB), inactive 241 031 (≈3.68 GiB), speculative 976 (≈15 MB) → доступно по
  формуле `thermal.py` ≈ **3.9 GiB**, при пороге Eco ≥4 GiB.
- **Почему риск:** следующий Eco-рендер может быть отклонён admission-гейтом; при
  `unknown`-профиле консервативный режим (900 с, партия ≤2).
- **Доказательство:** `vm_stat`, `sysctl hw.memsize`, `worker/thermal.py` (38 тестов).
- **Ограничение:** реальный live-тест thermal — только один Eco-рендер NLB-25
  (`docs/REPORTS/WP_THERMAL_03_REPORT.md` §11.2); остальное — mock-тесты.
  Полный thermal acceptance — **NOT VERIFIED** (нет повторного живого прогона).
