# Guinness: Night Shift — acceptance и блокеры (preflight)

> Дата: 2026-11-04. Документ описывает, как принимать ролики, когда останавливаться и
> что мешает. GPU не запускался, ролики не создавались, approve не выставлялся.

---

## 1. Базовые правила приёмки

1. `approved` выставляет **только человек**; агент не утверждает ролики, не заменяет
   `approved_attempt_id` и не перезаписывает approved-ассеты.
2. Ревью — после **каждого** шота, до постановки следующего. Batch из пяти запрещён.
3. Preview-попытку (`parameters.preview=true`, 73 кадра) утвердить нельзя: API вернёт
   409 `preview_cannot_be_approved`.
4. Оригиналы (576×1024 MP4) остаются в хранилище; финальная сборка — отдельный
   артефакт `source=export`, destructive editing не выполняется.
5. Любой «не проверено» помечается `[ПРОВЕРИТЬ]` с точной командой.

---

## 2. Критерии качества одного ролика

Оценка по каждому пункту: `ок` / `замечание` / `брак`.

| № | Критерий | Что смотреть |
|---|---|---|
| 1 | Identity consistency | тот же кот: шоколадная маска, тёмные уши/хвост, жёлто-зелёные глаза; нет второго кота |
| 2 | Анатомическая стабильность | четыре лапы, нет лишних конечностей, морда не «плывёт», уши не меняют форму |
| 3 | Motion quality | действие читается и завершается в пределах 8 с; нет рывков и «слайд-шоу» |
| 4 | Camera stability | камера фиксирована, нет дрейфа и зума, горизонт ровный |
| 5 | Lighting consistency | ночь, лунный холодный + тёплая лампа; нет дневного света и вспышек |
| 6 | Temporal consistency | фон и предметы не меняются между кадрами; фантик/чашка не исчезают |
| 7 | Audio quality | дорожка не клиппует, нет гула и щелчков; LTX-аудио не выдаётся за речь |
| 8 | Dialogue clarity | реплика разборчива **только** если записана отдельно; LTX-речь не оценивается как диалог |
| 9 | Lip sync accuracy | **N/A**: движка нет. Артикуляция не имитируется промптом |
| 10 | MP4 tech | h264, 576×1024, 24 fps, 193 кадра, ≈8,04 с, `aac` 48 кГц stereo |
| 11 | Провенанс | `render_attempts.parameters` заполнены, `workflow_snapshot` есть, артефакт с sha256 |

## 3. Протокол ревью после каждого шота (6 шагов)

| Шаг | Проверка | Команда / источник | Ожидание |
|---|---|---|---|
| 1 | MP4 | `ffprobe -v error -show_entries stream=codec_name,width,height,nb_frames,r_frame_rate,channels,sample_rate -of default=nw=1 <file>` | h264, 576×1024, 193, 24/1, aac 48 кГц 2 канала |
| 2 | Пик памяти | `render_attempts.parameters` → `peak_mem_mb`, `min_available_mb`, `max_pressure_level` | фиксируем; если `max_pressure_level=4` → §4 |
| 3 | Thermal | `parameters.thermal` + `~/.mary-studio/thermal-events.jsonl` | `thermal_state`, cooldown, отсутствие `critical` |
| 4 | Журнал | `GET /api/jobs/{job_id}/events`, `last_event` | нет `lease_expired`, `external_prompt_lost`, `retry_wait` без причины |
| 5 | Качество | §2, просмотр целиком | нет брака по identity/анатомии/камере |
| 6 | Разрешение | явное «дальше» от человека | без него следующий run не создаётся |

Дополнительно фиксируется: `artifact_id`, `sha256`, `bytes`, `storage_key`,
`attempt_id`, `seed`, `render_seconds`, `preset`/`preset_source`, `workflow_version`.

Примеры проверок:

```bash
curl -sS "$API/api/jobs/$JOB/events"
curl -sS "$API/api/shots/$SHOT/attempts"
psql -d mary_studio -At -c "select parameters->>'peak_mem_mb', parameters->>'max_pressure_level', parameters->>'preset' from render_attempts where id='$ATTEMPT';"
pgrep -fl caffeinate || echo "caffeinate не запущен"
```

## 4. Memory guard и thermal guard

### 4.1 Жёсткие правила

1. Один тяжёлый GPU job в любой момент времени (атомарный guard `render_video` в
   `claim`, `series/next` при чужом активном рендере → `busy`).
2. Thermal guard не отключается: профиль `eco`, питание от сети, `caffeinate`.
3. При `max_pressure_level=4` (critical) **следующий** GPU job не создаётся и не
   стартует. Событие фиксируется (attempt `parameters`, thermal JSONL, отчёт), человеку
   предлагается корректировка (например, `low_ram=true` по §4 RENDER_CONFIG или пауза).
4. Если `min_available_mb` < 1 500 — пауза и разгрузка памяти до следующего шота.
5. Два critical подряд — серия останавливается, дальнейшие параметры не подбираются
   автоматически.

### 4.2 Что **не** обещается

Безопасное прерывание уже отправленного в ComfyUI prompt не гарантируется:
`/interrupt` глобальный, cancel-эндпоинта для конкретной job нет (Q-18). Отмена серии
помечает run/items, но текущий prompt дорабатывает. Поэтому решение о запуске шота
принимается до отправки.

## 5. Финальная сборка (acceptance)

| Проверка | Ожидание |
|---|---|
| Длительность | ≈40,2 с (5 × 8,042 с, без переходов) |
| Формат | MP4, H.264, AAC, 1080×1920, 24 fps, `+faststart` |
| Звук | единая музыкальная дорожка + реплики + эффекты; интегрированная громкость ≈ −16 LUFS, TP ≤ −1,5 dBTP |
| Провенанс | `artifacts.source='export'`, `metadata` с clips/audio_artifact_id/sha256 |
| Оригиналы | пять MP4 576×1024 не изменены, sha256 до/после совпадают |
| Утверждение | только после approve пяти попыток человеком |

Сборка возможна в двух вариантах (AUDIO_PLAN §7.3): локальный mux для ревью и штатный
экспорт с `audio_artifact_id` для финала.

## 6. J. Список блокирующих ограничений

| № | Ограничение | Тип | Что разблокирует |
|---|---|---|---|
| J-01 | Пик памяти 16,3 ГБ, pressure 4 (critical) на базовом профиле | железо | поднимать только один параметр за тест; при 4 — стоп |
| J-02 | Lip sync отсутствует (`SELECTED_ENGINE=None`, 409) | продукт | Q-01: MLX-модель, лицензия, замер памяти |
| J-03 | TTS отсутствует: нет движка и весов (Qwen3-TTS/Kokoro — пустые каталоги) | продукт | Q-03 + разрешение на установку |
| J-04 | Согласие на голос не зафиксировано | юридическое | Q-02 |
| J-05 | Генератора музыки нет; права на mp3 NLB не подтверждены | продукт/права | оригинальный трек с лицензией |
| J-06 | Генерации изображений нет (SDXL/IPAdapter отсутствуют) | продукт | внешний инструмент, если понадобится новый кадр |
| J-07 | Стартовые кадры 392–396 px по ширине → апскейл 1,56–1,66× | качество | новые кадры ≥576 px по ширине |
| J-08 | Нет `POST /api/projects` и `POST /api/characters` | API | создание только через `import_series`; запись персонажа требует скрипта |
| J-09 | Нет API для `prompt_revisions` | API | штатный путь — манифест `import_series` |
| J-10 | Провенанс ревизий помечен `nine_lives_band_manifest` | косметика | правка кода (вне объёма) |
| J-11 | `output_prefix` всегда `nlb/…` | косметика | правка `ltx_adapter` (вне объёма) |
| J-12 | Preview нельзя утвердить (409) | инвариант | by design |
| J-13 | Нет безопасной отмены отправленного prompt (Q-18) | инфраструктура | решение принимается до запуска |
| J-14 | Одна дорожка на проект, стемов нет (Q-09) | продукт | сведение до загрузки |
| J-15 | 1080×1920 не рендерится; единственный 9:16 — 576×1024 | железо | апскейл только на экспорте |
| J-16 | ComfyUI сейчас не запущен | состояние среды | поднять перед рендером |
| J-17 | Внешние сервисы запрещены (D8) | политика | решение человека |

## 7. Чек-лист готовности к первому рендеру

- [ ] Человек утвердил motion-промпты (дословные или варианты §4.1 плана)
- [ ] Человек выбрал путь создания проекта (`import_series`) и подтвердил отсутствие
      записи `characters`
- [ ] Проект создан, сцена и 5 шотов существуют, motion-ревизии v1 на месте
- [ ] 1 identity + 5 стартовых кадров загружены и **approved** человеком
- [ ] У всех 5 шотов `start_keyframe_artifact_id` заполнен через `promote-keyframe`
- [ ] `series/preflight` → `start_frames 5/5`, `references ok`
- [ ] Backend и ComfyUI запущены, `/system_stats` 200, активных `render_video` = 0
- [ ] Питание от сети, заряд ≥ 50 %, pressure = normal, свободно ≥ 4 ГиБ
- [ ] Закрыты тяжёлые приложения, Ollama не держит модели
- [ ] Выдано разрешение **только** на GNS-01

## 8. Формат отчёта после каждого шота

```text
Шот: GNS-0X
Статус: completed | failed
Артефакт: <id>, sha256 <…>, <bytes> Б, <WxH>, <frames> кадров, <duration> с
Попытка: <attempt_id>, seed <…>, render_seconds <…>
Память: peak_mem_mb <…>, min_available_mb <…>, max_pressure_level <…>
Thermal: thermal_state <…>, power <…>, cooldown <…>
Журнал: <события / отсутствие аномалий>
Качество: identity / анатомия / движение / камера / свет / звук — по пунктам §2
Не проверено [ПРОВЕРИТЬ]: <что и какой командой>
Решение: жду разрешения на GNS-0Y
```

После отчёта — остановка до явного «дальше».
