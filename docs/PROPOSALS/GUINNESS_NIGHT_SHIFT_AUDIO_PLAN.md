## 5. Голос: варианты для решения человека

| Вариант | Что нужно | Риск | Статус |
|---|---|---|---|
| A. Запись человека (рекомендуется) | диктофон/микрофон, 5 файлов WAV 48 кГц, согласие на голос | требуется человек и его время; голос должен быть постоянным | доступно после согласия |
| B. Субтитры вместо голоса | FFmpeg `drawtext` или вшитые титры на этапе монтажа | «говорящий» кот без звука читается слабее; текст поверх видео меняет кадр | доступно |
| C. Немой вариант | только ambience/SFX | реплики из сценария пропадают | доступно |
| D. Внешний TTS-сервис | ключ, передача текста наружу | D8 запрещает внешние сервисы в MVP; лицензия и приватность | **не разрешено** |
| E. Локальный TTS | установка весов (Qwen3-TTS / Kokoro) + память | 1,7B модель делит память с LTX; лицензии не проверены | **требует разрешения** |

Рекомендация: вариант A. Если голоса нет — вариант B для GNS-02…05 и A только для
GNS-01/05 (начало и финал), чтобы не терять драматургию.

## 6. Музыка: спецификация (статус BLOCKED)

Единая тема на ≈40,2 с (5 × 8,042 с), лёгкий ночной джаз, комедийный характер.

| Параметр | Значение |
|---|---|
| Темп | 84–92 BPM, свинг 8-е, ощущение «крадущейся» походки |
| Инструменты | контрабас (pizzicato, walking), приглушённое пиано (Rhodes/felt), щётки по тарелке, редкий кларнет/вибрафон как акцент |
| Форма | 8 с вступление (GNS-01) → 8 с A (GNS-02) → 8 с B (GNS-03) → 8 с «вопрос» (GNS-04) → 8 с кодa (GNS-05) |
| Динамика | −18 LUFS под речью, подъём до −14 LUFS в паузах; без ударных «дропов» |
| Громкость финала | интегрированная −16 LUFS, true peak ≤ −1,5 dBTP |
| Права | только оригинал или трек с подтверждённой лицензией; внешние сервисы запрещены без разрешения |

Наличие в проекте: в NLB есть загруженный `audio/mpeg` 384 983 Б
(`projects.audio_artifact_id = 67af1e71…`, `source=upload`) — происхождение
пользовательское, **права не подтверждены**, использовать для GNS нельзя без решения.

Итог: музыка **BLOCKED**. Подготовлена только спецификация; утверждать, что тема
сгенерирована, нельзя.

## 7. Сведение и финальная сборка

### 7.1 Дорожки на шот (после появления голоса/музыки)

1. `gns_XX_dialogue.wav` — сухая речь, 48 кГц stereo, −18 LUFS.
2. `gns_XX_ambience.wav` — комната/улица, −30…−26 LUFS.
3. `gns_XX_sfx.wav` — 1–4 коротких эффекта.
4. `gns_XX_music.wav` — вырезка общей темы 8,042 с (обрезка по сэмплам, без сдвига фазы).

### 7.2 Сведение одного шота

```bash
ffmpeg -y \
  -i gns_01_dialogue.wav -i gns_01_ambience.wav -i gns_01_sfx.wav -i gns_01_music.wav \
  -filter_complex "[0:a]volume=1.0[d];[1:a]volume=0.35[a];[2:a]volume=0.8[s];\
[3:a]volume=0.30[m];[d][a][s][m]amix=inputs=4:duration=longest:normalize=0,\
loudnorm=I=-16:LRA=11:TP=-1.5" \
  -ar 48000 -ac 2 -c:a pcm_s16le gns_01_mix.wav
```

### 7.3 Два пути применения

| Путь | Как | Плюсы | Ограничения |
|---|---|---|---|
| Локальный (ревью) | `ffmpeg -i clip.mp4 -i gns_XX_mix.wav -map 0:v -map 1:a -c:v copy -c:a aac -b:a 192k -shortest out.mp4` | не трогает approved-попытку и артефакт | файл вне БД, провенанс — вручную |
| Штатный (финал) | собрать мастер 40,21 с, загрузить `POST /api/artifacts`, вызвать `POST /api/projects/{id}/exports` с `audio_artifact_id` | провенанс в БД, один MP4 1080×1920 | экспорт **заменяет** звук клипов целиком → мастер должен содержать речь + SFX + музыку |

Порядок финальной сборки: пять клипов (`shot_id` + `attempt_id`) → экспорт
1080×1920 / 24 fps / h264 crf 18 / `aac 192k` / `+faststart`; оригиналы 576×1024
остаются в хранилище нетронутыми.

### 7.4 Провенанс

Голос, ambience, SFX и музыка загружаются отдельными артефактами (`source=upload`)
с `metadata` (что это, откуда, лицензия, длительность). Финальный экспорт хранит
`audio_artifact_id`, список клипов и sha256. Реконструкция «из чего собран звук»
остаётся возможной.
