## 2. Что изменено в движке (`backend/app/mouth_animation.py`)

| Пункт | Было (v1) | Стало (v2) |
|---|---|---|
| Версии | `pillow_ellipse_v1` / `mouth_animation_mvp_v1` | `pillow_mouth_v2` / `mouth_animation_mvp_v2` |
| Кривая | release `max(0.05, base·(1−0.5·smoothing))` | release `max(0.08, base·(1−0.35·smoothing))` |
| Паузы | только release, рот оставался приоткрыт | непрерывная тишина ≥ `SILENCE_CLOSE_S = 0.08` с → `openness = 0` |
| Форма | тёмный эллипс, центр смещён вниз | плоский верх на линии губ, раскрытие только вниз, `rounded_rectangle` |
| Размер | `rh·(0.18 + 0.72·norm)` вверх и вниз | `rh·(0.10 + 0.55·norm)` вниз от линии губ |
| Край | жёсткий, alpha `0.35 + 0.65·norm` | feather `0.12·open_height`, alpha `0.45 + 0.55·norm` |
| Патч | `hypot(rw, rh) + 2` (обрезал маску снизу) | `2·max(rw, rh) + 16` (маска не обрезается) |
| Длительность | `-shortest` (срезал хвост записи) | `-af apad` + `-t`; хвост записи сохраняется |
| `frames` | длина кривой (285), в файле 284 | фактическая длительность MP4 (285 = ffprobe) |

Кадр с закрытым ртом по-прежнему побайтно равен источнику (ветка `openness <= 0`
не менялась). Детерминизм сохранён: одинаковые вход и калибровка дают одинаковые кадры.

## 5. Визуальная и техническая приёмка v2

Проверка по 71 кадру, извлечённому из MP4 с `fps=6` (PNG, без потерь при извлечении),
сравнение с первым кадром ролика:

| Критерий | Результат |
|---|---|
| Рот на морде, не на глазу/носу | **PASS** — изменения только в `x 0.60…0.69`, `y 0.466…0.499` (под носом, в пределах морды) |
| Нет изменений вне области | **PASS** — максимум 2 пикселя на кадр вне допустимой рамки (шум x264 на усах) |
| Нет прямоугольных границ маски | **PASS** — мягкий край, видимой рамки нет |
| Нос, глаза, усы не деформируются | **PASS** — вне области рта кадры совпадают с источником |
| Рот закрыт в паузах | **PASS** — кадры `t = 2.67–3.0`, `6.17–6.33`, `7.83–8.17`, `11.5–11.67` совпадают с закрытым кадром (сигнал 0.0) |
| Короткая пауза 0.16 с | **PASS по кривой** — закрытие через 2 кадра при 24 fps (тест `test_openness_curve_closes_mouth_in_short_pause`); в 6-fps выборке отдельные такие паузы могут не попасть в кадр |
| Движение связано с речью | **PASS** — корреляция «потемнение рта ↔ RMS-огибающая» r = 0.78, лаг 0 кадров; пик речи `t = 0.67` |
| Звук синхронизирован | **PASS** — MP4 ↔ рабочая WAV: r = 1.0, лаг 0 мс, RMS 2794.0 vs 2802.3, пик 20305 vs 20298 |
| Хвост записи не срезан | **PASS** — 285 кадров / 11.875 с, аудио длиннее исходного рабочего WAV на 49 мс (`apad`) |
| MP4 воспроизводится | **PASS** — `ffprobe` читает оба потока, браузерный путь review не менялся |
| Остаточные дефекты | рот — стилизованная тёмная «пасть» без зубов/языка; синхронизация по громкости, не phoneme-accurate |

## 8. Отклонения от плана

1. Патч кадра увеличен до `2·max(rw, rh) + 16`: при прежнем `hypot(...)` новая маска
   обрезалась снизу и давала плоский низ — исправлено до приёмки.
2. Высота раскрытия снижена с `0.12 + 0.68·norm` до `0.10 + 0.55·norm`: при первом
   прогоне «пасть» уходила на подбородок.
3. UI-предупреждение о зоне глаз (вариант «плюс UI») не делалось — выбран полный объём
   без UI; сама область теперь задана по данным кадра.
4. `frames` теперь берётся из фактической длительности, поэтому значение изменилось
   285 вместо 284 при прежней схеме `-shortest`.
